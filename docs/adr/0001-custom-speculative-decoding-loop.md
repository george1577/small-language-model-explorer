# Custom speculative decoding loop instead of vLLM or `generate(assistant_model=...)`

The example script runs speculative decoding through vLLM, which needs an NVIDIA GPU, and Hugging Face's built-in version (`generate(assistant_model=...)`) hides each round inside the library. The app's whole point is to show every round: what the draft model proposed, what the target model would have picked, how many drafts were accepted, and which token the target added. So the Speculative decoding tab runs on our own small loop (`slm_lab/speculative.py`) over two functions, `propose` and `verify`, backed by a KV cache that is cut back after rejections. Verification is greedy (accept a draft only if it is the target's own top token), which guarantees the output equals the target model's greedy output and makes the loop easy to test with fake models. We accept that this is a teaching copy: no sampling-mode acceptance (only shown as a number), no batching, and speed-ups on a laptop CPU are far smaller than vLLM's on a GPU.
