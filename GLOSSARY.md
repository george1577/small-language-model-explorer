# Small Language Model Explorer

A learning tool for seeing how a small language model can replace or speed up a large one, using distillation, quantization, and speculative decoding.

## Language

### Models and their roles

**Small language model (SLM)**:
A language model with few enough parameters (here, around 1 billion or fewer) to run cheaply on modest hardware.
_Avoid_: Tiny model, mini model

**Large model**:
The bigger, more capable model that a small language model is compared against or learns from.
_Avoid_: Big model, LLM (ambiguous: both are LLMs)

**Teacher**:
The large model whose next-token distributions serve as the learning target during distillation.
_Avoid_: Oracle

**Student**:
The small model being trained to imitate the teacher during distillation.
_Avoid_: Learner

**Target model**:
The large model whose output speculative decoding must reproduce; it verifies drafted tokens.
_Avoid_: Base model, verifier, main model

**Draft model**:
The small model that proposes tokens cheaply during speculative decoding.
_Avoid_: Speculative model, assistant model, helper

### Knowledge distillation

**Synthetic training data**:
Training text written by a model rather than collected from people; here, Python snippets generated by Claude.
_Avoid_: Fake data, generated dataset

**Knowledge distillation**:
Training a student to match a teacher's full next-token distributions, not just the correct next token.
_Avoid_: Model compression (too broad), fine-tuning (too general)

**Hard label**:
The single correct next token from the training text, treated as 100% probability.
_Avoid_: Ground truth, one-hot target

**Soft label**:
The teacher's full next-token distribution at a position, including the probability it gives to wrong-but-plausible tokens.
_Avoid_: Soft target, dark knowledge (that names what soft labels carry, not the labels)

**Task loss**:
The cross-entropy between the student's distribution and the hard label.
_Avoid_: LM loss, CE loss

**Distillation loss**:
The KL divergence between the teacher's and student's temperature-softened distributions, multiplied by the temperature squared.
_Avoid_: KD loss, soft loss

**Distillation temperature (T)**:
The number logits are divided by before softmax during distillation; above 1 it flattens distributions so small probabilities become visible.
_Avoid_: Sampling temperature (a different setting used at generation time)

**Alpha (α)**:
The weight given to distillation loss versus task loss in the combined loss.
_Avoid_: Mixing ratio, lambda

### Quantization

**Quantization**:
Storing model weights with fewer bits each, trading a little accuracy for a smaller memory footprint.
_Avoid_: Compression

**NF4**:
A 4-bit number format whose 16 levels are spaced to match the bell-curve shape of neural-network weights.
_Avoid_: int4, 4-bit float

**Quantization block**:
A run of consecutive weights that share one scale factor when quantized.
_Avoid_: Group, chunk

**Quantization error**:
The difference between a weight's original value and its value after quantizing and de-quantizing.
_Avoid_: Rounding loss, noise

**Perplexity**:
How surprised a model is by a text on average; lower means the model predicts the text better.
_Avoid_: Accuracy, loss (related but not the same number)

### Speculative decoding

**Speculative decoding**:
Generating text by letting the draft model propose several tokens and having the target model accept or reject them in a single pass, producing the target model's output faster.
_Avoid_: Assisted generation, speculative sampling

**Speculation length (k)**:
How many tokens the draft model proposes per round.
_Avoid_: Lookahead, num_speculative_tokens

**Round**:
One cycle of speculative decoding: the draft proposes k tokens, then the target verifies them and adds one token of its own.
_Avoid_: Step, iteration

**Correction**:
The target model's own token added at the first position where it disagrees with the draft.
_Avoid_: Replacement, fix

**Bonus token**:
The extra token the target model adds at the end of a round in which every drafted token was accepted.
_Avoid_: Free token, extra token

**Acceptance rate**:
The fraction of drafted tokens the target model accepts.
_Avoid_: Hit rate, success rate

**Throughput**:
Tokens generated per second of wall-clock time.
_Avoid_: Speed, latency (the inverse view)
